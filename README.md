# 🚀 FEASIBILITY AI
### 🤖 منصة ذكية لإعداد دراسات الجدوى الاقتصادية والمالية

**حوّل فكرتك إلى مشروع مدروس، واتخذ قراراتك الاستثمارية بناءً على البيانات والتحليل المالي الذكي.**

منصة SaaS عربية متكاملة تجمع بين دقة الحسابات المالية وقوة الذكاء الاصطناعي، لمساعدة رواد الأعمال والمستثمرين والشركات على إعداد دراسات الجدوى الاقتصادية والمالية، وتحليل المخاطر، وتقييم الفرص الاستثمارية، وإنشاء تقارير احترافية.

🌍 **السوق المستهدف:** جمهورية مصر العربية 🇪🇬  
🌐 **اللغة:** العربية بالكامل  
↔️ **اتجاه الواجهة:** RTL  
💻 **نوع المشروع:** Software as a Service (SaaS)

---

## 📌 نبذة عن المشروع

**FEASIBILITY AI** هي منصة متخصصة في أتمتة إعداد دراسات الجدوى الاقتصادية والمالية، توفر بيئة رقمية متكاملة تبدأ من إدخال بيانات المشروع، مرورًا بتحليل التكاليف والإيرادات والتمويل، وصولًا إلى حساب المؤشرات الاستثمارية وإصدار التقارير المالية.

تعتمد المنصة على محرك مالي مستقل لإجراء الحسابات، ومساعد ذكاء اصطناعي مسؤول للمساعدة في تحليل المعلومات وتنظيمها وتفسيرها، مع الفصل بين الحسابات المالية والمخرجات التوليدية للذكاء الاصطناعي.

🎯 **هدفنا:** جعل إعداد دراسات الجدوى أكثر سهولة وشفافية وتنظيمًا، مع توفير أدوات تساعد المستخدم على فهم فرص الاستثمار والمخاطر والنتائج المتوقعة.

## ✨ المميزات الرئيسية

### 🧮 1. محرك مالي مستقل ودقيق

يُعد المحرك المالي القلب الأساسي للمنصة، وقد صُمم لتنفيذ الحسابات المالية بصورة مستقلة عن واجهة المستخدم وخدمات الذكاء الاصطناعي.

**أهم الوظائف المالية:**

- 📊 إعداد قائمة الدخل المتوقعة.
- 💵 إعداد التدفقات النقدية للمشروع وحقوق الملكية.
- ⚖️ إعداد الميزانية العمومية والتحقق من توازنها.
- 📉 حساب الإهلاك بالقسط الثابت والرصيد المتناقص.
- 🏦 إنشاء جداول القروض والأقساط وفترات السماح والرسوم.
- 🧾 حساب الضرائب مع ترحيل الخسائر وفق القواعد المطبقة.
- 🔄 تقدير رأس المال العامل.
- 📈 إدراج التضخم والنمو وأسعار الصرف.
- 🏭 تحليل الطاقة التشغيلية ونسب التشغيل والهالك.
- 💰 حساب صافي القيمة الحالية (NPV).
- 📈 حساب معدل العائد الداخلي (IRR).
- 👥 حساب معدل العائد الداخلي لحقوق الملكية.
- ⏳ حساب فترات الاسترداد العادية والمخصومة.
- 🎯 تحليل نقطة التعادل بالقيمة والوحدات.
- 💹 حساب العائد على الاستثمار (ROI).
- 🛡️ حساب نسبة تغطية خدمة الدين (DSCR).
- 📊 حساب مؤشر الربحية.
- 🔬 إجراء تحليل الحساسية.
- 🔀 إنشاء السيناريوهات المالية.
- ⚡ إجراء تحليلات What-if الفورية.

✅ يستخدم المحرك مكتبة `decimal.js` للحسابات العشرية.  
🧪 وفق حالة المشروع الموثقة، اجتاز المحرك **31 اختبارًا مرجعيًا**.
